## About

I am a master's student in **Business Informatics** and work in the financial IT environment. My main interests lie at the intersection of data analysis, machine learning and software engineering.

I particularly enjoy projects where the result is more than a model or a notebook: a reproducible pipeline, a well-defined process or a tool that can actually be used and understood.
