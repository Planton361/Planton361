# Version 1 editing guide

## Upload layout

Copy the contents of this directory into the root of:

```text
Planton361/Planton361
```

The repository should contain:

```text
README.md
assets/
├── welcome.gif
└── photo-album/
    ├── fraud-prioritization.png
    ├── life-os.png
    ├── fh-agent.png
    └── firered-randomizer.png
```

## Important checks before publishing

1. All four featured project repositories are currently private.
2. Review whether the visible descriptions reveal only information you want public.
3. Keep `Repository: Private`, or replace it only after a repository becomes public.
4. Check the animated header on desktop and mobile.
5. Confirm that the external typing-SVG service loads correctly.
6. Preview the README directly on GitHub before committing to `main`.

## Header behavior

`assets/welcome.gif`:

- displays `WELCOME TO MY SPACE` for approximately 20 seconds;
- then changes to `You have been here as long as you can remember`;
- does not intentionally loop;
- keeps the final message visible.

GIF playback behavior can vary slightly with browser caching and rendering.

## Replacing an album image

Keep the same filename and replace the file under `assets/photo-album/`.

Recommended:

- square image;
- 1000 × 1000 px;
- PNG;
- retain enough contrast for GitHub light and dark themes;
- avoid small technical text inside the photograph.

## Recent Notes

Version 1 uses manually curated notes between:

